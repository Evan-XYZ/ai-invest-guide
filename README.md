# 《AI 投资指南》

**AI 在投资里最成熟的能力，是替你把信息降噪、及时梳理；判断永远是你自己的。**

[![License: CC BY-NC 4.0](https://img.shields.io/badge/license-CC%20BY--NC%204.0-2F7857.svg?style=flat-square)](LICENSE)
[![网页版](https://img.shields.io/badge/网页版-yongmai.xyz-A6533C.svg?style=flat-square)](https://yongmai.xyz/ai-invest-guide/)

8 篇，是我一年多把 AI 用进投资的真实样本：投研、策略、操盘、复盘、Agent，每一层为什么这么搭、我踩过什么坑、你可以直接拿走什么。作者：勇麦（十一年 A 股 + 美股实盘，一年多重度用 AI 做投研、决策和复盘）。

> 不荐股，不预测涨跌，不接任何交易接口。这是我自己这一版的做法和样本，不是标准答案。

## 方法 · 动作 · 打样

**指南给方法，ymskill 给动作，YMOS 是照着方法搭好的一份样板。** 三样可以单独用，也能叠着用。

| | 是什么 | 从这里开始 |
|:---|:---|:---|
| **方法** · 这份指南 | 每一步为什么这么做 | 从 [00 全景导读](./00-overview.md) 开始，或按痛点挑一篇 |
| **动作** · [ymskill](https://github.com/Evan-XYZ/ymskill) | 指南的可运行版本：1 个总入口、7 个模块、28 个动作，装进你自己的 Agent | 已经有自己的笔记库，只想要动作 |
| **打样** · [YMOS](https://github.com/Evan-XYZ/YMOS) | 照着方法搭好的一整套 AI 结构化投资系统：投研层、策略内核层、操盘层 | 想要一套现成的系统，照着用或魔改 · [文档](https://yongmai.xyz/ymos-docs/) |

我的建议是先读懂方法，再用 YMOS 和 ymskill。那时你更能看懂它们为什么这么设计、哪里不适合你，然后按自己的需求改，而不是整套照搬。

## 让你的 AI 读这份指南

这些文件是纯 Markdown，可以整份丢给你的 Agent。比如：

```text
读一下 https://github.com/Evan-XYZ/ai-invest-guide 的 00-overview.md，按文末「可带走资产」那段问我 5 个问题，判断我先读哪篇。不要给我任何具体股票或买卖建议。
```
